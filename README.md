## Descripción del proyecto

TIENDA_PRO es un sistema de gestión de indumentaria
desarrollado en lenguaje C.

El programa permite administrar una tienda de ropa
mediante menús interactivos en consola.

Su objetivo es facilitar la gestión de productos,
usuarios, proveedores, stock y ventas.

## Funcionalidades principales

- Registro de usuarios y contraseñas.
- Acceso según el tipo de usuario.
- Menús para administrador, empleado, proveedor y cliente.
- Gestión de productos y categorías.
- Consulta y control de stock por talles.
- Registro de ventas.
- Cálculo de precios y descuentos.
- Almacenamiento de información en archivos.

## Conceptos de programación utilizados

- Variables y constantes.
- Condicionales if, else y switch.
- Ciclos for, while y do while.
- Arreglos.
- Estructuras struct.
- Funciones.
- Archivos de texto.
- Validación de datos.

## Organización del programa

El sistema cuenta con diferentes menús según
el tipo de usuario.

### Administrador
Permite administrar información de la tienda.

### Empleado
Permite consultar productos y gestionar mercadería.

### Proveedor
Permite consultar información relacionada
con los pedidos.

### Cliente
Permite consultar prendas y realizar compras.

## Archivos

El programa utiliza archivos de texto para
guardar información y recuperarla en otras
ejecuciones.

## Cómo ejecutar el programa

1. Descargar el archivo .c correspondiente
   a la versión final.
2. Abrirlo en Code::Blocks.
3. Compilar el programa.
4. Ejecutarlo.
5. Seleccionar una opción del menú principal.
